# 🚀 CachyOS Control Center — Das All-in-One Administrations-Cockpit für CachyOS

Das **CachyOS Control Center** bringt Windows-Umsteigern und erfahrenen Linux-Enthusiasten das perfekte Zusammenspiel aus Übersicht und Kontrolle. Egal ob du ein vollwertiges TUI-Dashboard oder schnelle Terminal-Befehle bevorzugst: Mit einem Tastendruck wechselst du zwischen deutscher und englischer Sprache und steuerst deine Hardware optimal an.

### 🎮 Features auf einen Blick
- **Umschaltung Deutsch / Englisch:** Taste `L` im TUI oder Parameter `--lang en`/`--lang de`.
- **Hardware- & Lüfter-Telemetrie:** Überwache CPU-Takt, GPU-Power und RAM-Belegung in Echtzeit.
- **Gaming-Power auf Knopfdruck:** Wechsle blitzschnell auf den Performance-Governor.
- **Wartung & Updates:** Pacman-Cache bereinigen, verwaiste Pakete entfernen und BTRFS-Zustand prüfen.

### Installation
```bash
git clone https://github.com/Graba92/cachyos-control-center.git
cd cachyos-control-center
./setup.sh
python3 app.py
```
